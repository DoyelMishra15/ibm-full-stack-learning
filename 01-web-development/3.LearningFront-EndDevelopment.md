# Learning Front-End Development

## 1. What Is Front-End Development?

The **front end** of a website is the part that users directly interact with.

Examples:

* Navigating between pages
* Choosing product categories
* Comparing products
* Clicking buttons
* Filling out forms
* Viewing text, images, and videos

A **front-end developer** builds the structure, appearance, and interactive behavior of this part of a website.

---

# 2. The Three Core Technologies

Web developers commonly use three technologies together:

| Technology     | Main Purpose                         |
| -------------- | ------------------------------------ |
| **HTML**       | Creates the structure of the website |
| **CSS**        | Styles and designs the website       |
| **JavaScript** | Adds interactivity and functionality |

These technologies are designed to **work together**.

### Easy mental model

> **HTML = Structure**
> **CSS = Appearance**
> **JavaScript = Behavior**

For example, for a login button:

* **HTML** → creates the login button
* **CSS** → controls its appearance
* **JavaScript** → adds the login functionality

---

# 3. HTML — Structure of a Website

**HTML (Hypertext Markup Language)** is used to create the physical structure of a website.

HTML can contain elements such as:

* Text
* Links
* Images
* Videos
* Page dividers
* Buttons

HTML code also provides proper formatting so that browsers can display text and image elements consistently.

### Analogy

Think of a website as a house:

> **HTML = The constructed house**

It provides the basic structure that everything else is built upon.

---

# 4. CSS — Styling the Website

**CSS (Cascading Style Sheets)** is used to make websites visually appealing.

CSS provides a standard way to:

* Define styles
* Apply styles
* Manage styles
* Control the appearance of website components

CSS can control:

* Fonts
* Colors
* Layouts
* Designs
* Overall look and feel

### HTML vs CSS

> **HTML creates the structure.**
> **CSS designs and styles the structure.**

### Example

A website may use:

* HTML → create a button
* CSS → give the button a color, font, size, and layout

---

# 5. Cross-Browser and Device Compatibility

CSS can also be used to help create websites with **cross-browser compatibility**.

### Cross-browser compatibility

A website is cross-browser compatible when it works across multiple browsers.

Websites also need to work across different types of devices, such as:

* PCs
* Mobile devices
* iPads

A front-end developer needs to ensure that websites work properly across different browsers and devices.

---

# 6. JavaScript — Interactivity

**JavaScript** is an object-oriented programming language used together with HTML and CSS to add **interactivity** to websites.

JavaScript can make websites:

* Interactive
* Intuitive
* Functional
* Responsive to user actions

### Login button example

Suppose a website has a login button:

1. **HTML** creates the login button.
2. **CSS** styles the button.
3. **JavaScript** adds the login functionality.

So:

> **HTML → what exists**
> **CSS → how it looks**
> **JavaScript → what it does**

---

# 7. SASS

**SASS (Syntactically Awesome Style Sheets)** is an extension of CSS.

It is compatible with all versions of CSS.

SASS provides features such as:

* Variables
* Nested rules
* Inline imports

These features help keep styles organized.

SASS can also make creating style sheets **faster and easier**.

### Key idea

> **SASS extends CSS with additional features that help organize and simplify styling.**

---

# 8. LESS

**LESS (Leaner Style Sheets)** is another technology that enhances CSS.

LESS:

* Adds additional styles and functions
* Is backwards compatible with CSS

**LESS.js** is a JavaScript tool that converts LESS styles into CSS styles.

### SASS vs LESS

Both are used to extend/enhance CSS.

| Technology  | Purpose                                                                |
| ----------- | ---------------------------------------------------------------------- |
| **SASS**    | Extends CSS with features such as variables, nested rules, and imports |
| **LESS**    | Enhances CSS with additional styles and functions                      |
| **LESS.js** | Converts LESS styles into CSS                                          |

---

# 9. Adaptive vs Responsive Websites

Modern websites can be designed to work across different screen sizes.

Two approaches discussed in this lesson are **adaptive** and **responsive** design.

## Adaptive Design

An **adaptive website** displays a version of the website designed for a **specific screen size**.

For example:

* A PC may receive a version containing more information.
* A mobile device may receive a version designed specifically for its smaller screen.

### Key idea

> **Adaptive = designed versions for specific screen sizes.**

---

## Responsive Design

A **responsive website** automatically resizes/adapts to the device on which it is being accessed.

For example:

A product website opened on a mobile device can automatically adapt to the smaller screen while still displaying its features.

### Key idea

> **Responsive = automatically adapts to the available screen/device.**

---

# 10. JavaScript Frameworks

A **JavaScript framework** is an application framework written in JavaScript.

Programmers can use and manipulate its functions where required to create applications that work across devices.

The lesson discusses several examples:

* Angular
* React.js
* Vue.js

---

# 11. Angular

**Angular** is an open-source framework maintained by **Google**.

Angular allows websites to render HTML pages quickly and efficiently.

It also has built-in tools for:

* Routing
* Form validation

### Key idea

> **Angular = JavaScript framework with built-in tools such as routing and form validation.**

---

# 12. React.js

**React.js** was developed and is maintained by **Facebook**.

It is described in the lesson as a **JavaScript library** used to build and render components for a web page.

React.js is **not a complete suite of tools**.

For example:

* Routing is not part of React.js itself.
* Routing needs to be added using a third-party tool.

React.js primarily helps developers build and place components into a page.

### Key idea

> **React.js = JavaScript library focused on building and rendering web-page components.**

---

# 13. Vue.js

**Vue.js** is maintained by the community.

Its main focus is the **Vue layer**, which includes:

* User interfaces
* Buttons
* Visual components

According to the lesson, Vue.js is:

* Flexible
* Scalable
* Adaptable
* Able to integrate well with other frameworks

It can function as either a **library or a framework**.

### Key idea

> **Vue.js = flexible and adaptable technology focused on the user-interface layer.**

---

# 14. Front-End Development Continuously Evolves

Front-end development is constantly changing.

Technologies are continuously upgraded, so front-end developers need to continuously upgrade the websites they create.

Websites should work across:

* Multiple browsers
* Multiple operating systems
* Multiple devices

Therefore, front-end development requires continuous learning and adaptation.

# 17. Key Definitions

### Front End

The part of a website that users interact with.

### HTML

Hypertext Markup Language; used to create the structure of a website.

### CSS

Cascading Style Sheets; used to style and design websites.

### JavaScript

An object-oriented programming language used to add interactivity to websites.

### SASS

Syntactically Awesome Style Sheets; an extension of CSS.

### LESS

Leaner Style Sheets; technology that enhances CSS.

### Adaptive Design

Displays a version of a website designed for a specific screen size.

### Responsive Design

Automatically adapts/resizes a website to the device or screen being used.

### JavaScript Framework

An application framework written in JavaScript that provides functionality developers can use to build applications.

### Cross-Browser Compatibility

The ability of a website to work across multiple browsers.
