 # 01 — Web Development

This folder contains the learning materials and practice work for the web-development section of the IBM Full Stack Learning path.

## Topics covered

- Web development fundamentals
- HTML structure and semantic markup
- CSS styling, layout, and responsive design
- JavaScript fundamentals and browser interaction
- Building and organizing web pages
- Exercises and project-based practice

## How to use this folder

1. Start with the introductory materials.
2. Work through the examples in order.
3. Complete the exercises and projects after each topic.
4. Open HTML files in a browser and use the browser developer tools to inspect and debug them.

## Prerequisites

- A modern web browser
- A code editor such as Visual Studio Code
- Basic familiarity with files, folders, and the command line

## Learning goals

By completing this section, you should be able to create structured web pages, style them with CSS, add interactivity with JavaScript, and organize a small front-end project.
