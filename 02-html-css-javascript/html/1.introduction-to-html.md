# Introduction to HTML

## 1. What Is HTML?

**HTML** stands for **Hypertext Markup Language**.

It is a **markup language** used to describe documents that can be displayed as web pages on the Internet.

HTML can be thought of as:

> **The language of the Internet**

HTML was originally designed for sharing **scientific documents**, but it evolved over time to support many different types of documents displayed as web pages.

---

# 2. HTML Elements

**HTML elements** are the building blocks of an HTML page.

Different pieces of content are assigned labels describing what they represent.

Examples include:

* Paragraph
* List
* Table

These elements are represented using **HTML tags**.

### Important distinction

> **HTML elements = building blocks of a page**
> **HTML tags = markup used to represent those elements**

Browsers do not display the tags themselves.

Instead, browsers interpret the tags and use them to **render the content**.

---

# 3. How HTML Works

A simplified process is:

```text id="h6x2cn"
HTML Document
      ↓
HTML Tags / Elements
      ↓
Web Browser interprets them
      ↓
Rendered Web Page
```

For example, a paragraph element tells the browser that a piece of content should be treated as a paragraph.

# 5. W3C and HTML Standards

The **World Wide Web Consortium (W3C)** made recommendations to HTML standards over the years.

As HTML evolved:

* New features were added.
* Specifications changed.
* HTML became capable of supporting more types of web content.

---

# 6. WHATWG and HTML5

The **Web Hypertext Application Technology Working Group (WHATWG)** initially worked independently on recommendations.

In **2007**, the W3C formed a working group to work with WHATWG on developing the **HTML5 specification**.

Since 2007, W3C and WHATWG worked together on the development of the HTML5 standard.

The transcript notes that W3C published its specification under W3C copyright, while a version with a less restrictive license was maintained on the WHATWG site.

---

# 7. HTML5

**HTML5** is the HTML specification discussed in this course.

The HTML5 specification defines a single language called **HTML5** that can be written using:

* HTML syntax
* XML syntax

---

# 8. Objectives of HTML5

The transcript identifies several objectives of HTML5.

## 8.1 Single Language

HTML5 defines a single language that can be written in:

* HTML syntax
* XML syntax

---

## 8.2 Interoperability with Earlier Implementations

HTML5 defines a **processing model** that can interoperate with earlier HTML implementations.

In other words, HTML5 was designed with compatibility with earlier HTML implementations in mind.

---

## 8.3 Improved Document Markup

HTML5 improves the **markup used for documents**.

---

## 8.4 Web Storage, Video, and Audio

HTML5 includes markup and APIs for web-related capabilities such as:

* Web storage
* Video
* Audio

This expanded what could be supported directly through HTML and its associated APIs.

# 11. Key Concepts to Remember

### HTML

A markup language used to create documents that can be displayed as web pages.

### HTML Element

A building block of an HTML page representing content such as a paragraph, list, or table.

### HTML Tag

Markup used to represent an HTML element. Browsers interpret tags rather than displaying them directly.

### HTML5

The HTML specification covered by this course, supporting HTML/XML syntax, interoperability with earlier implementations, and markup/APIs for capabilities such as web storage, video, and audio.

### W3C

World Wide Web Consortium, which made recommendations concerning HTML standards.

### WHATWG

Web Hypertext Application Technology Working Group, which worked with W3C on HTML5 development.
